# Tabela periódica (Python)

Consulta de elementos da tabela periódica no terminal. Lê os dados de `tabela.csv` e mostra símbolo, nome,
número atômico, massa atômica, configuração eletrônica e posição na tabela.

Projeto de estudo, baseado na 1ª atividade do professor Fahad Kalil, para praticar dicionários em Python.

## Rodar

```bash
python TabelaPeriodica.py
```
